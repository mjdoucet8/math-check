Built-in image generation was used for all six runtime raster assets. Original Numora PNGs were local style references; they were not copied into the repository. The geometry guide is a code-derived diagram of the existing playable quay. Generated alpha was preserved. Sprite registration/cropping occurs in the game engine; the generated PNGs are unchanged.
